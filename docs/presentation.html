Scheduler

Multi-tenant, reliable background-job processing.

Spring Boot · PostgreSQL · JWT · Docker · JUnit

Problem & solution

  • Users own projects; projects own queues; queues hold jobs.
  • Workers claim work atomically with PostgreSQL SKIP LOCKED.
  • Delayed, recurring, batch, retry and dead-letter workflows are first-class.

Reliability by design

  • Priority-aware atomic claims prevent duplicate concurrent execution.
  • Retry policies: fixed, linear, exponential; failures land in a DLQ.
  • Heartbeats and stale-job reclamation self-heal interrupted work.

Security & usability

  • JWT authentication and ownership checks protect tenant data.
  • Validation rejects malformed job and scheduling requests.
  • Browser dashboard exposes projects, queues, jobs, recurring jobs, DLQ and workers.

Evidence

  • ./mvnw test: 27 passing tests.
  • Deliberate broken datasource: application-context test fails.
  • Restored H2 test configuration: full suite passes without PostgreSQL.
